# GalaxyOS 2

GalaxyOS 2 is a from-scratch Linux distribution: its own kernel, a BusyBox system, a Weston desktop and
ready-to-run apps. Downloads are on the [Releases page](https://github.com/besko614-cmyk/galaxy2os/releases/latest).
